# API Documentation

Full interactive API documentation is auto-generated by springdoc-openapi and served at:

- **Swagger UI**: `http://localhost:8080/swagger-ui.html`
- **OpenAPI JSON**: `http://localhost:8080/api-docs`

The AI service exposes its own interactive docs at `http://localhost:8000/docs`.

All backend endpoints below are prefixed with `/api/v1` and (except `/auth/**`) require
an `Authorization: Bearer <accessToken>` header.

## Authentication (`/auth`)

| Method | Path | Description |
|---|---|---|
| POST | `/auth/register` | Create a new account (default role `ROLE_USER`) |
| POST | `/auth/login` | Authenticate and receive access + refresh tokens |
| POST | `/auth/refresh` | Exchange a refresh token for a new token pair |
| POST | `/auth/logout` | Revoke a refresh token |

## Dashboard (`/dashboard`)

| Method | Path | Description |
|---|---|---|
| GET | `/dashboard/summary` | Security score, threat/incident stats, trends, recent activity |

## Threats (`/threats`)

| Method | Path | Description |
|---|---|---|
| POST | `/threats/detect` | Submit raw event features; forwarded to the AI service for classification, persisted, and auto-responded to (Admin/Analyst) |
| GET | `/threats` | Paginated list, filterable by `severity` / `type` |
| GET | `/threats/recent` | Last 10 detected threats |
| GET | `/threats/{id}` | Threat detail |
| PATCH | `/threats/{id}/status?status=` | Update threat status (Admin/Analyst) |

## Incidents (`/incidents`)

| Method | Path | Description |
|---|---|---|
| POST | `/incidents` | Create an incident |
| GET | `/incidents` | Paginated list, filterable by `status` |
| GET | `/incidents/recent` | Last 10 incidents |
| GET | `/incidents/{id}` | Incident detail |
| PATCH | `/incidents/{id}` | Update status / assignee / resolution notes |
| POST | `/incidents/{id}/comments` | Add a comment |
| GET | `/incidents/{id}/comments` | List comments |
| GET | `/incidents/{id}/timeline` | Full audit timeline for the incident |

## Automated Incident Response (`/response-actions`) — Admin/Analyst only

| Method | Path | Description |
|---|---|---|
| GET | `/response-actions` | Paginated action history |
| POST | `/response-actions/block-ip` | Manually block an IP |
| POST | `/response-actions/disable-user/{userId}` | Manually disable a user account |
| POST | `/response-actions/quarantine/{threatId}` | Mark a threat as quarantined/mitigated |
